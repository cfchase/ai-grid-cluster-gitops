# AI Grid cluster GitOps

The component library for AI Grid on ACM: a hub, its sites, and the models they serve. A deployment repository pins
this repository at one commit, selects components and sets their inputs.

To install, create your deployment repository from the template
[`ai-grid-cloud/ai-grid-deployment-template`](https://github.com/ai-grid-cloud/ai-grid-deployment-template) with **Use this template**,
and follow its [install guide](https://github.com/ai-grid-cloud/ai-grid-deployment-template/blob/main/docs/install/README.md).
The [component reference](docs/install/README.md) stays here, versioned with the components.
